# Portfólio - Marlon Miranda Jr.

Portfólio pessoal de desenvolvedor Full Stack (Node.js, MySQL, APIs REST).

## Estrutura

```
portfolio-marlon/
├── index.html              # Estrutura da página (HTML)
├── css/
│   └── style.css           # Estilos customizados (glassmorphism, scrollbar, toast...)
├── js/
│   ├── tailwind-config.js  # Tema do Tailwind (cores, fontes, animações)
│   └── main.js             # Interações (menu mobile, filtro de skills, copiar e-mail, formulário)
└── assets/
    └── img/
        └── foto-marlon.jpg # Foto de perfil
```

## Como usar

Abra o `index.html` no navegador. Não precisa de instalação ou build.

> Tailwind, Font Awesome e Google Fonts são carregados por CDN, então é necessário ter internet.

## Tecnologias

HTML5, TailwindCSS (CDN), JavaScript, Font Awesome e Google Fonts.
